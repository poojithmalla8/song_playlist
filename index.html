Song Playlist

Songs from Malla's Instagram saved collections English songs and Songs playlist (plus the 1-post Songs collection) — 245 posts pulled, 352 unique songs verified by title + artist. The same list is the Spotify playlist Instagram Songs and the backend database in this repo (data/songs-*.json).

Language and song type are estimates unless stated otherwise; see the README for how each was derived. Links marked “search” open a search for that song on the service instead of a verified track page.

Sources: Instagram post links are in each song's database record (source_posts). 135 posts named no title + artist in caption or reel description — mostly carousel threads whose songs live only in slide images — and are listed as unverified in the README rather than guessed. Spotify matching was exact title + artist; 6 songs had no confident Spotify match and are not in the Spotify playlist.
